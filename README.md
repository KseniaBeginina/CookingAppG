# 🍳 YumPlan – Cooking App

Modern Android cooking application with clean UI and intuitive recipe planning.

## ✨ About the Project

YumPlan is a cooking and meal planning application that allows users to:

- Browse recipes
- View detailed cooking instructions
- Plan meals for a week
